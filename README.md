# اپ اندروید

یک پروژه بسیار ساده اندروید:

- کل صفحه آبی است.
- یک دکمه «خروج» در پایین صفحه دارد.
- با زدن دکمه، برنامه بسته می‌شود.

## اجرا

1. پوشه پروژه را در Android Studio باز کن.
2. اجازه بده Gradle Sync انجام شود.
3. روی Run بزن.

## فایل اصلی برنامه

`app/src/main/java/com/example/appandroid/MainActivity.java`
